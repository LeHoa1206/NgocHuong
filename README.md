# 学中文 - Học Tiếng Trung Cùng Em ❤️

Ứng dụng học tiếng Trung với 200 câu chuyện song ngữ (HSK 3 & HSK 4)

## Tính năng

- 📚 200 câu chuyện song ngữ Trung-Việt
- 🎯 Phân loại theo HSK3 và HSK4
- 🔍 Tìm kiếm câu chuyện
- 📂 Lọc theo danh mục: Cuộc sống, Tình yêu, Ẩm thực, Du lịch, Công việc
- ✅ Đánh dấu câu đã học
- 📖 Từ vựng quan trọng kèm Pinyin
- ⌨️ Hỗ trợ phím tắt (←/→ để chuyển câu, ESC để đóng)

## Cài đặt

```bash
npm install
npm start
```

Mở trình duyệt tại: http://localhost:3000

## Deploy lên Render

1. Push code lên GitHub
2. Tạo Web Service mới trên Render.com
3. Kết nối với GitHub repository
4. Build Command: `npm install`
5. Start Command: `npm start`

## Công nghệ

- HTML5, CSS3, JavaScript
- Express.js (cho production)
- LocalStorage (lưu tiến độ học)
